# Changelog

All notable changes to the UI Design Library are documented here.

## 1.0.0 — 2026-11-21

First release of the MCP server and CLI, plus the audit and auto-fit work.

### Added

- **MCP server + CLI (`mcp/`, npm package `ui-design-library-mcp` 1.0.0).**
  TypeScript, official MCP SDK, stdio transport, no login, no API keys.
  Tools: `search_elements`, `list_categories`, `get_element`
  (html / css / all-in-one / react), `get_similar`, `get_random`.
  Search never returns code; at most one element's code per call.
  Index cached in memory and on disk, refreshed when the data version
  changes. Resources for the index and categories; prompt
  `use-ui-element`. CLI `ui-lib`: `search`, `get`, `list`, `random`,
  `add`, with `--json`. 10 tests pass (unit + stdio integration against
  the live data).
- **Machine-readable data.** `data/index.min.json` (compact index of all
  3,805 elements), `data/categories.json`, one API file per element at
  `api/<category>/<id>.json` (metadata, html, css, combined single-file
  version), `data/featured.json` (the 9 home-page strip elements), and
  `llms.txt`. Regenerated by `scripts/generate-api-data.py`.
- **"Use with AI agents" page** (`#/ai-agents`) with copy-ready config for
  Claude Desktop, Claude Code, Cursor, VS Code and Windsurf, plus an
  example conversation and the `ui-lib` commands. Same section added to
  the README.
- **SEO / social.** Open Graph + Twitter Card meta, `sitemap.xml`,
  `robots.txt`, friendly static `404.html`.

### Fixed

- **Auto-fit previews.** Every preview now measures its content
  (including the hover/active state) and scales it to fit, clamped
  0.25–1.6×. Full-screen elements (all 103 patterns + 3 using 100vw/100vh)
  render in a fixed 800×500 virtual viewport scaled to fit. Cards use a
  consistent 4:3 box; the preview stage is 16:9 with a Fit / 100% toggle.
  Per-element overrides in `data/overrides.json`. QA: 370 checks, 0 cropped.
  Findings in `docs/PREVIEW-ISSUES.md`.
- **Audit fixes** (`docs/AUDIT.md`). Home page no longer fetches five whole
  category files (~1.3 MB) for the strip (Lighthouse home performance
  55 → 86, LCP 9.5 s → 1.9 s). Browse preview preloading reduced
  (600 px → 200 px, performance 63 → 71). Browse cards are keyboard
  accessible (tabindex, role, Enter/Space). Empty search state now shows.
  Preview navigation race fixed (stale renders bail out). Message-listener
  leak in the preview controls fixed.
- **Browse race.** Navigating between browse categories could show the
  previous category's cards (loading flag + generation guard).
